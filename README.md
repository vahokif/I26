This is a modern patch for the classic game Interstate '76.

# Features

* Works out of the box on modern Windows and Wine with OpenGL acceleration
* Unlocked resolution with correct scaling
* Borderless fullscreen
* Unlocked framerate
* 1997-accurate simulation interpolated to the higher framerate
* Texture and GUI replacement from webp files
* Fixed incorrect music playing on the GoG version

# Experimental features

* New terrain renderer without popping

# Installation
Unpack the i26 directory from the zip into the installation directory of the [GoG version](https://www.gog.com/en/game/interstate76) and run `i26/install.bat`.
