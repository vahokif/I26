This is a reimplementation of the classic game Interstate 76 in Godot engine.

# Features

* Modernized graphics
* 1997 mode - toggle the original graphics any time with F12
* Multiplayer with modern netcode
* Auto-reverse (optional)
* Support for upscaled textures

# Installation
Unpack the i26 directory from the zip into the installation directory of the [GoG version](https://www.gog.com/en/game/interstate76) or Nitro Pack, and run
