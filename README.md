This is a modern patch for the classic game Interstate '76 and Nitro Pack.

# Features

* Works out of the box on modern Windows and Wine with OpenGL acceleration
* Unlocked rendering framerate without physics problems - the simulation runs at lower FPS and is interpolated smoothly
* Unlocked resolution with correct scaling
* Borderless fullscreen
* Texture and GUI replacement from webp files
* Fixed incorrect music playing on the GoG version

# Experimental features

* New terrain renderer without popping

# Installation
Unpack the i26 directory from the zip into the installation directory of the [GoG version](https://www.gog.com/en/game/interstate76) and run `i26/install.bat`. Same for Nitro Pack.
