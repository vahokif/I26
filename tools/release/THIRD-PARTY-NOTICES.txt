anet 0.10 (GNU LGPL 2.1): the lobby protocol behind INTERNET's game lists
  (src/I76.Net/Anet). I26's client is C# written for it; the dpio reliable
  transport, the dptab table packets, the session record, the login,
  INDIRECT_JOIN and REQUEST_OPEN were ported from anet's source (h/dppkt.h,
  h/dptab.h, h/anet.h, src/dp/dpio.c, src/dp/dptab.c, src/dp/dp2.c,
  demo/utils/dpcrc32.c). LGPL 2.1 section 3 allows such code to be carried
  under the GNU GPL, which covers I26 as a whole (version 3).
  Copyright (C) 1995-2001 Activision, Inc. Released under the LGPL in 2001,
  maintained by Dan Kegel: http://kegel.com/anet/ (mirror:
  https://github.com/Nielk1/anet). I26 contains none of anet's binaries and
  speaks to anet game servers only to list games and introduce players.

LZMA SDK (public domain): the LZMA and LZMA2 formats as the SDK by Igor Pavlov
  describes them (https://www.7-zip.org/sdk.html); I26's decoder
  (src/I76.Formats/Installers/Lzma.cs) is its own compact implementation of them.

The Complete Asset Bible for Interstate '76/Gold/Nitro (html 4th edition, 23 Feb 2017)
  by DIVER, building on a text version by Skull N. Bones (8 Mar 1998) and an original
  document by Brian Dean Jennings. https://route380.stars.ne.jp/i76/resource_i76/i76cab4.zip
  The map editor's object picker takes its labels from it: the object names' descriptions
  (src/I76.Editor/Objects/asset-bible.tsv, which lists only each name, its description and the
  section it sits in; none of the bible's pictures, tables or pages), and its notes on which
  objects are broken or never appear.

Data sources used at runtime (the map editor's New map from real world; fetched from the internet when the player asks,
  kept in the user's own cache folder, never shipped with I26):
  OpenStreetMap: the map picker's tiles (tile.openstreetmap.org), the place search (Nominatim) and the roads of a map made
  from the real world (the Overpass API). (c) OpenStreetMap contributors, available under the Open Database Licence (ODbL):
  https://www.openstreetmap.org/copyright. Maps made with the roads carry that credit in a text file beside the map files
  and the ODbL's share-alike applies to the road data in them. The tile server's usage policy is followed (a User-Agent naming
  I26, a disk cache, at most two connections, no bulk downloads): https://operations.osmfoundation.org/policies/tiles/
  Terrain heights: Mapzen / AWS Terrain Tiles (https://registry.opendata.aws/terrain-tiles/), which are made from several
  public datasets, among them USGS 3DEP and NASA SRTM (credits: https://github.com/tilezen/joerd/blob/master/docs/attribution.md).
